# Wait what

Source: https://github.com/mattpocock/skills (skills/productivity/wait-what), MIT, (c) 2026 Matt Pocock. Adapted by UPEX Galaxy.

Wait, I don't understand where you've got to here. Re-pitch that: give me a little bit of context, talk in ASD-STE100 Simplified Technical English, and use the project's ubiquitous language. That language lives in the glossary the repo keeps (a `GLOSSARY.md`, or the domain docs the project names); if the repo has several, follow the map to the right one. A repo with no glossary gets plain words and each term defined once.
